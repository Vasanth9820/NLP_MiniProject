# AI Content and Plagiarism Detection System Using NLP

A college-level NLP mini project that detects similarity between documents and estimates whether text is AI-generated or human-written.

---

## Description

This application provides two core capabilities:

1. **Plagiarism / Similarity Detection** — Compares multiple uploaded documents using TF-IDF vectorization and cosine similarity. Results are displayed as a similarity matrix, a heatmap, and a ranked list of sentence-level matches.

2. **AI Content Detection** — A trained machine learning classifier (TF-IDF + Logistic Regression) estimates whether a given piece of text is likely AI-generated or human-written, along with a confidence score.

> ⚠️ **Important:** Similarity scores indicate textual overlap and do not automatically prove plagiarism. AI detection results are probabilistic estimates and should not be treated as definitive proof.

---

## Features

- Upload **TXT**, **PDF**, and **DOCX** files (multiple files simultaneously)
- Paste text directly into the application
- **Document-level similarity** matrix and heatmap (TF-IDF + Cosine Similarity)
- **Sentence-level matching** with configurable threshold
- **AI vs. Human text classification** with probability scores
- Visual charts (bar charts, heatmap) powered by Plotly
- **Downloadable reports** in TXT and HTML formats
- Clean, tabbed Streamlit dashboard
- Configurable similarity thresholds
- Graceful error handling for corrupt / empty files

## Installation

### 1. Clone or download the project

```bash
cd ai_plagiarism_detector
```

### 2. (Recommended) Create a virtual environment

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

NLTK data (punkt, stopwords, wordnet) is downloaded automatically on first run.

---

## Running the Application

```bash
streamlit run app.py
```

Open the URL shown in the terminal (usually `http://localhost:8501`).

---

## Training the AI Detector

### Dataset format

Create (or replace) `data/ai_text_dataset.csv` with two columns:

```csv
text,label
"Your text here...",human
"AI-generated text here...",ai
```

Labels must be exactly `ai` or `human`. A minimum of ~200 samples per class is recommended for meaningful results. The included demo dataset has 50 samples for testing only.

### Run the training script

```bash
python train_model.py
```

The trained model is saved to `models/ai_detector.pkl` and loaded automatically by the application.

## Usage

1. Start the application with `streamlit run app.py`.
2. In the sidebar, upload one or more documents (TXT/PDF/DOCX) **or** paste text directly.

4. Click **🔍 Analyse**.
5. Browse results across the **Overview**, **Similarity Analysis**, **AI Detection**, and **Report** tabs.

## Limitations

- **Similarity ≠ Plagiarism.** A high similarity score means textual overlap, not necessarily academic dishonesty. Context and intent matter.
- **AI detection is probabilistic.** The classifier can produce false positives and false negatives, especially on short texts (<50 words).
- **Dataset quality matters.** The demo dataset is very small. Results improve significantly with a larger, diverse dataset.
- **PDF extraction.** Scanned or image-based PDFs cannot be parsed; only text-based PDFs are supported.
- **Language.** The system is designed for English text only.
- **Human review required.** The system is an aid for human reviewers, not a replacement.
